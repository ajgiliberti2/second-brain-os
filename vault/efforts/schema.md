# Efforts — Schema

**Purpose:** Active projects and initiatives. Things you're working toward.

**Route here when:** Content describes a project, goal, or initiative — especially if it has a status, owner, or timeline.

**Status vocabulary:** `Active` · `On Hold` · `Complete`

**Route to atlas instead when:** Content is reference knowledge, not a project.  
**Route to calendar instead when:** Content is a time-indexed event or meeting note.
