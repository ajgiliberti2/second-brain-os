# Skill Map

> All defined skills available in this vault.

## Available Skills

| Skill | Type | What it is |
|---|---|---|
| **ForeverNote** | Framework | The daily note container — structural pattern all time-based workflows write into |
| **Meeting Notes** | Workflow | Routes meeting exports across calendar + atlas + efforts in one pass |
| **Journal Prompts** | Data | Day-of-week prompt pool — read directly by iOS Shortcut or any automation |

**Framework** = structural pattern other workflows depend on.  
**Workflow** = specific process that produces content.  
**Data** = structured file read directly by a tool or shortcut.
