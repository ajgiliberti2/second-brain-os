# Calendar — Schema

**Purpose:** Time-indexed records. Things that happened on a specific date.

**Route here when:** Content has a date and is a record of something that occurred — a meeting, a daily note, a briefing, a journal entry.

**File naming:** `month-day.md` — e.g. `april-14.md`. One file per calendar date, forever. Years stack as `## YYYY` sections inside the same file.

**Route to atlas instead when:** Content is reference knowledge with no expiry.  
**Route to efforts instead when:** Content is a project update with no specific date anchor.
